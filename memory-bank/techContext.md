# Tech Context: CaffeineMD

- **Stack**: Next.js 15+ (App Router), React 19, TypeScript, Tailwind CSS v4.
- **Editor**: `@tiptap/react`, `@tiptap/starter-kit`, `@tiptap/suggestion`, extensions for tables, task lists, code blocks, images.
- **Database & Graph**: `dexie`, `dexie-react-hooks`, `d3-force`.
- **Sync & Serialization**: `js-yaml`, Google Drive REST API with multipart chunking.
- **Constraints**: Local-first storage; separate `PluginKey` instances for ProseMirror suggestion plugins; universal emoji font fallback via Google Fonts `Noto Color Emoji`.
